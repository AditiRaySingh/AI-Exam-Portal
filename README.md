# 🌟 OVERVIEW

**AI Exam Portal** is a full-stack web-based examination platform designed to make online assessments more **efficient, secure, intelligent and user-friendly**.

The system provides separate experiences for:

| 🎓 Student | 👨‍🏫 Teacher | 🛡️ Admin |
|:---:|:---:|:---:|
| Take Exams | Create Exams | Manage Platform |
| View Results | Manage Questions | Manage Users |
| Track History | AI Question Generation | Monitor System |
| Analyze Performance | Publish Exams | Platform Control |

The platform combines:

> 🧠 **AI Assistance** + 📝 **Online Examinations** + 📊 **Analytics** + 🔐 **Secure Authentication**

into one complete application.

# 💜 WHY AI EXAM PORTAL?

Traditional examination systems often require teachers to manually create questions, manage exams, evaluate answers and analyze results.

This platform brings these processes together in one place.

🚀 INSTALLATION
1️⃣ Clone the Repository
git clone https://github.com/AditiRaySingh/AI-Exam-Portal.git
cd AI-Exam-Portal
2️⃣ Backend Setup
cd backend

Install dependencies:

npm install

Start the backend:

npm start
3️⃣ Frontend Setup

Open another terminal:

cd frontend

Install dependencies:

npm install

Start the frontend:

npm run dev
🔑 ENVIRONMENT VARIABLES

Create a .env file inside the backend directory.

PORT=3000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GROQ_API_KEY=your_ai_api_key

⚠️ Important: Never upload .env files or API keys to GitHub.

📊 Metric	Description
🎯 Score	Marks obtained
📈 Percentage	Overall performance
✅ Correct	Correct answers
❌ Wrong	Incorrect answers
⏭️ Skipped	Unanswered questions
🏆 Result	Pass / Fail
⏱️ Time Taken	Examination duration
