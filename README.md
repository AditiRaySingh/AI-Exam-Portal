## 🌟 WHAT IS AI EXAM PORTAL?

> **AI Exam Portal** is a full-stack online examination system that combines
> **secure exam management, automated evaluation, AI-assisted question generation,
> role-based dashboards and performance analytics** into one platform.

# 🎨 PLATFORM HIGHLIGHTS

| 🧩 Module | 🚀 Capability |
|---|---|
| 🎓 Student Portal | Browse, attempt and submit examinations |
| 👨‍🏫 Teacher Portal | Create, manage and publish examinations |
| 🤖 AI Engine | Generate questions from prompts/material |
| 📊 Analytics | Track marks, attempts and performance |
| 🔐 Authentication | JWT-based role authentication |
| 🛡️ Exam Security | Attempt control and monitoring |
| 📝 Evaluation | Automatic objective evaluation |
| 🏆 Results | Scores, percentages and performance details |
