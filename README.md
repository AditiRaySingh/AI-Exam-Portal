# 🧠 AI Exam Portal

### AI-Powered Full-Stack Online Examination Platform

A modern examination platform built with the **MERN stack**, combining online assessments, AI-assisted question generation, answer evaluation, role-based access control, and performance analytics.

---

## 📌 Overview

**AI Exam Portal** is a full-stack online examination system designed for **Students, Teachers, and Administrators**.

The platform manages the complete examination lifecycle:

- Exam creation and configuration
- Question management
- AI-assisted question generation
- Study-material-based question generation
- Online examination
- Answer evaluation
- Result generation
- Performance analytics
- Role-based access control
- Duplicate attempt protection

The goal is to reduce manual effort for teachers while providing students with a structured and interactive examination experience.

---

## ✨ Key Features

### 🎓 Student

- Secure registration and login
- View published examinations
- Start and attempt examinations
- Countdown timer
- Question navigation
- Answer submission
- Automatic result calculation
- View score and percentage
- View correct, wrong and skipped answers
- Examination history
- Duplicate attempt protection

### 👨‍🏫 Teacher

- Create and configure examinations
- Add and manage questions
- Generate questions using AI
- Generate questions from study material
- Review and modify generated questions
- Publish examinations
- View student results
- View examination analytics
- Track student attempts and performance

### 🛡️ Admin

- Admin dashboard
- User management
- Student management
- Teacher management
- Platform statistics
- Administrative operations
