## 📌 Project Overview

**AI Exam Portal** is a full-stack online examination system designed for:

| 👨‍🎓 Student | 👨‍🏫 Teacher | 🛡️ Admin |
|:---:|:---:|:---:|
| Attempt Exams | Create Exams | Manage Users |
| View Results | Manage Questions | Manage Students |
| Track Performance | Generate Questions with AI | Manage Teachers |
| View History | Publish Exams | Platform Statistics |

The platform manages the complete examination lifecycle from **exam creation
to student performance analytics**.

# 🤖 AI-Powered Capabilities

AI is integrated directly into the examination workflow to reduce teacher effort.

### 🔄 AI Question Generation

📄 Study Material
       ↓
🤖 AI Processing
       ↓
📝 Generated Questions
       ↓
🔍 Teacher Review
       ↓
🚀 Published Examination

🤖 AI Feature	🎯 Purpose
🧠 AI Question Generation	Generate examination questions
📄 Material-Based Generation	Generate questions from study material
🤖 AI Answer Evaluation	Assist with answer evaluation
🔍 Teacher Review	Review and modify AI-generated questions
⚡ Faster Preparation	Reduce manual question creation


💡 Important: The teacher remains in control of the final question
review and examination.

👨‍🏫 Teacher Workflow

🔐 Security & Authentication
The application uses JWT-based authentication and
role-based authorization.
🔄 Authentication Flow
👤 User
   ↓
🔐 Register / Login
   ↓
🎟️ JWT Token
   ↓
🛡️ Protected API Request
   ↓
👮 Role Authorization
   ↓
✅ Requested Resource

🛡️ Security Features
Security Feature	Implementation
🔐 Authentication	JWT
🛡️ Protected Routes	Authentication Middleware
👥 Authorization	Role-Based Access Control
🚫 Duplicate Attempts	Attempt Validation
⏱️ Exam Timing	Start / End Time Validation
🙈 Correct Answers	Hidden During Examination
📤 Answer Submission	Protected API

🚀 Installation & Setup
1️⃣ Clone Repository
git clone https://github.com/AditiRaySingh/AI-Exam-Portal.git
cd AI-Exam-Portal

2️⃣ Backend Setup
cd backend
npm install
npm start

3️⃣ Frontend Setup
Open another terminal:
cd frontend
npm install
npm run dev

🔑 Environment Variables
Create a .env file inside the backend directory.
PORT=3000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GROQ_API_KEY=your_ai_api_key

⚠️ Security: Never commit .env files, database credentials,
JWT secrets, or AI API keys to GitHub.
